# Luxury Hotel & Resort

A responsive luxury hotel website built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Responsive navigation bar
- Hero section
- Featured rooms
- Rooms & Suites page
- Services page
- Gallery page
- Contact page
- Bootstrap cards
- Responsive layout
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git
- GitHub
